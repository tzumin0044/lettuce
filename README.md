# 🌿 生菜製作包裝與分組派工系統 (Lettuce Production & Distribution System)

本系統為生菜包裝產線專用之單一頁面整合系統（SPA），整合**每日製作數量明細**、**苔籃需求即時計算**、**外箱與品規標籤列印**以及**A/B/C組製作平衡派工**功能。

---

## 📑 系統分頁架構

| 分頁 | 功能名稱 | 說明 |
| :--- | :--- | :--- |
| **分頁 1** | 📋 製作數量明細表 | 輸入或貼上每日 Excel 製作數量，支援模糊比對、手寫自訂品項與即時統計。 |
| **分頁 2** | 🧺 苔籃計算 | **【新增功能】** 依規格自動計算橘苔、綠苔所需苔籃數，品項獨立分開顯示。 |
| **分頁 3** | 🏷️ 標籤列印管理 | 自動產生 84.9×62.4mm 外箱貼與 35×25mm 品規貼（含太陽日代碼與修邊標記）。 |
| **分頁 4** | 🌿 製作分組派工 | 根據各組工作人數（A/B/C組）動態平衡工作總重與包數，支援隨機換組與截圖。 |

---

## 🧺 苔籃計算規格與邏輯說明

生菜採收與包裝作業中，不同品項需分開裝入專用苔籃以防擠壓與混料。系統依據製作數量自動換算所需苔籃數：

### 1. 橘苔規格（1KG / 包）
- **裝載容量**：每苔 **3 入**（3包 / 苔）
- **使用苔色**：**橘苔**
- **計算公式**：
  $$\text{橘苔數} = \lceil \frac{\text{1KG製作數量}}{3} \rceil = \text{Math.ceil}(\text{數量} / 3)$$
- **尾數處理**：若有餘數，**無條件進位 1 苔**。
- **計算範例**：
  - 製作 16 包：$16 \div 3 = 5$ 餘 $1 \rightarrow 5 + 1 = \mathbf{6\text{ 苔}}$
  - 製作 15 包：$15 \div 3 = 5$ 餘 $0 \rightarrow \mathbf{5\text{ 苔}}$（整除）
  - 製作 1 包：$1 \div 3 = 0$ 餘 $1 \rightarrow 0 + 1 = \mathbf{1\text{ 苔}}$

---

### 2. 綠苔規格（300G / 包）
- **裝載容量**：每苔 **10 入**（10包 / 苔）
- **使用苔色**：**綠苔**
- **計算公式**：
  $$\text{綠苔數} = \lceil \frac{\text{300G製作數量}}{10} \rceil = \text{Math.ceil}(\text{數量} / 10)$$
- **尾數處理**：若有餘數，**無條件進位 1 苔**。
- **計算範例**：
  - 製作 16 包：$16 \div 10 = 1$ 餘 $6 \rightarrow 1 + 1 = \mathbf{2\text{ 苔}}$
  - 製作 20 包：$20 \div 10 = 2$ 餘 $0 \rightarrow \mathbf{2\text{ 苔}}$（整除）
  - 製作 7 包：$7 \div 10 = 0$ 餘 $7 \rightarrow 0 + 1 = \mathbf{1\text{ 苔}}$

---

### 3. 一個品項分開顯示原則
- **獨立分項呈現**：因各生菜品項（如紅捲生菜、綠火焰生菜、奶油生菜等）不可混苔裝籃，系統將每個品項分開獨立列出。
- **明細欄位**：
  - **製作品項名稱**
  - **🟧 橘苔區塊**：1KG 製作包數、橘苔苔數
  - **🟩 綠苔區塊**：300G 製作包數、綠苔苔數
  - **該品項苔數小計**：橘苔數 + 綠苔數
- **總計匯總列**：
  - 總橘苔數（包數、總苔數）
  - 總綠苔數（包數、總苔數）
  - 總苔籃數（橘苔 + 綠苔）

---

### 4. 快速輸出與分享功能
- 📸 **一鍵複製圖片傳 LINE**：使用 `html2canvas` 高解析度截取苔籃計算明細表格，直接寫入系統剪貼簿，在 LINE 按 `Ctrl+V` 即可貼上清晰圖檔。
- 📋 **一鍵複製文字傳 LINE**：一鍵產生排版工整之文字簡訊，方便於群組快速公告。
- ☑️ **僅顯示有製作數量的品項**：支援一鍵切換，預設僅過濾顯示本日有製作排程之品項，亦可取消勾選檢視全部 18 種品項。

## 🚀 操作流程

1. **輸入每日製作量**：
   - 開啟 `index.html`。
   - 在「📋 製作數量明細表」頁籤中直接手動輸入，或點擊「📋 一鍵貼上資料」貼入 Excel 表格。
2. **查看苔籃需求**：
   - 切換至「🧺 苔籃計算」頁籤。
   - 系統即時顯示各品項分開之橘苔與綠苔需求數量。
   - 點擊「📸 一鍵複製圖片傳 LINE」或「📋 一鍵複製文字傳 LINE」將資料發送至工作群組。
3. **標籤列印與分組派工**：
   - 依需求切換至「🏷️ 標籤列印管理」列印外箱貼或品規貼。
   - 切換至「🌿 製作分組派工」設定各組人數並隨機平衡派工。

---

## 🛠️ 技術規格
- **前端核心**：純原生 HTML5 / CSS3 / JavaScript（無額外建置工具，開箱即用）。
- **依賴套件**：
  - `html2canvas 1.4.1`（用以產生派工單與苔籃表截圖）。
- **列印支援**：內建 `@media print` 專用樣式，自動排除導航按鈕，僅輸出標籤排版。
